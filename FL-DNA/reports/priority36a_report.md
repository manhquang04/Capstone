# Priority36A — opt-in v2 key hardening

2026-10-12. Software validation COMPLETE, CPU only / one torch thread.
No training, record-recovery measurement, historical report change or commit.

## Changes and rationale

Default `DNATransformV2Config(hardened=False)` retains the existing seeded
algorithm. Pre-edit source snapshots are in `artifacts/priority36a/`;
old/new fixed-input sketches, reconstructions, metadata, statistics and RQ3
wire bytes compare exactly. The original RQ3 CLI/method selection is unchanged.
The additional config field is opt-in; no existing result is recomputed.

Hardened mode requires an out-of-band 16-byte key generated by
`secrets.token_bytes(16)`. RFC5869 HKDF-SHA256 derives full 32-byte sub-keys
with version, tensor index, purpose and quantization context labels.
Signs, coordinate selection and stochastic quantization consume distinct
HMAC-SHA256 counter streams. Rejection-sampled partial Fisher-Yates selection
avoids modulo bias. The hardened path never enters the legacy 32-bit seed
derivation or NumPy PRNG. HKDF is validated with RFC5869 SHA256 test vector 1.
[Specification](https://www.rfc-editor.org/rfc/rfc5869.html).

Public `HardenedV2Metadata` contains only shape, dimensions, ratio, eta,
quantization delta, tensor index and version. No seed, derived seed, key or
sampled coordinates are included. A receiver with the separate key derives
the coordinates/signs again. Missing/invalid keys fail before decoding.

RQ3 exposes separate `_serialize_v2_hardened` and
`_deserialize_v2_hardened` helpers, implemented in
`experiments/priority36a_wire.py`. The distinct versioned compact-JSON
format uses explicit little-endian float32 Base64 sketches and strict field
sets; unknown fields, duplicate JSON fields/tensor names, invalid dimensions,
bad Base64, unexpected lengths and non-finite values fail closed.
The legacy JSON functions themselves have identical ASTs to their snapshots.

## Usage

```python
from dna_encoder.transform_defense_v2 import DNATransformV2Config
from dna_encoder.transform_defense_v2_hardened import generate_v2_key
from experiments.priority36a_wire import (
    serialize_v2_hardened, deserialize_v2_hardened,
)

key = generate_v2_key()  # keep out of logs/config/payload; distribute securely
config = DNATransformV2Config(hardened=True)  # no legacy integer seed
payload, sender_reconstruction = serialize_v2_hardened(
    uploaded_non_bn_tensors, config, key=key,
)
receiver_reconstruction = deserialize_v2_hardened(payload, key=key)
```

The same keyword-only `key=` is supported by the transform/reconstruct array
APIs. Round-trip equality means exact float32 reconstruction bytes, not lossless
recovery of the original update. The legacy dense-projection audit explicitly
rejects hardened configs rather than silently using a truncated integer seed.

two eta settings), metadata/statistics equality, legacy wire encode/decode

## Limitations and preserved evidence

Hardening does not make v2 differentially private, encrypt sketches, hide the
data-dependent quantization delta, or establish reconstruction resistance.
It removes the explicit small-seed/index disclosure and small key-space design,
but no brute-force resistance or formal confidentiality claim is inferred from
these tests. A wrong but correctly sized key need not raise an error: this
format is not authenticated. Use authenticated transport and secure key
distribution/storage; fresh base keys per upload are recommended to avoid
reuse/correlation. Arbitrary caller-provided tensor names must not contain secrets.
Python immutable byte strings cannot guarantee secret-memory zeroization.

RQ1 conclusions remain unchanged: its adversary/server holds the decoding
seed/key. Existing scientific results and earlier artifacts/reports remain
unchanged; hardening has not been used to replace any historical experiment.
Default configuration representations gain the new opt-in field, but default
numerical outputs, public transform metadata and original wire bytes retain
their bit-for-bit contract. Keyed metadata is intentionally a separate schema.
