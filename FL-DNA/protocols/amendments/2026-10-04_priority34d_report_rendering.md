# P34D report rendering preflight

A new pure Markdown renderer is prepared before completed confirmatory data
access. It consumes independently assembled statistics and explicit audit
context, with no model execution or scientific file mutation. All raw and
Holm76/Holm211 p values, per-model and all-three pooled endpoint/effect
intervals, descriptive SSIM/MSE, matching decisions, clips/sigmas and
single-release epsilon scope remain visible. Gated tests are retained.

Completion wording requires an explicit verified-final-audit context. The
renderer itself never sets COMPLETE or writes the report. Synthetic fixtures
are not research outputs. The final analyzer must still verify manifests,
all stage-audit hashes, no-live workers, compilation and diff checks before
publishing a final report or completion receipt.
