# Published privacy-claim evidence table (Workstream 1)

**Scope and interpretation.** This is a source-level record of what the named *original* papers claim and evaluate; it is not a new empirical evaluation. `UNVERIFIED` means the original source read here did not establish the field. In particular, the request’s phrase “FedSKETCH / Privacy for Free” names two distinct mechanisms: FedSKETCH uses Count Sketch; *Privacy For Free: Wireless Federated Learning Via Uncoded Transmission With Adaptive Power Control* uses wireless channel noise and does **not** use Count Sketch. They are therefore recorded separately rather than attributed to one another.

| **PRECODE** — Scheliga, Mäder & Seeland, *PRECODE—A Generic Model Extension to Prevent Deep Gradient Leakage* (WACV 2022; preprint [arXiv:2108.04725](https://arxiv.org/abs/2108.04725)) | “PRECODE clearly outperforms other defense mechanisms by strongly improving privacy while maintaining model performance.” **Sec. 5.2, p. 6.** The mechanism-level claim is: “the gradient \(\nabla L(\hat y,y)\) does not contain direct information on the input sample \(x\).” **Sec. 3.2, p. 4.** | IGA / Inverting Gradients attack; CPL attack in Sec. 5.4. Attack: 10,000 Adam iterations, initial lr 0.1 with 0.1 decays at 3/8, 5/8, 7/8; \(\alpha_{TV}=0.05\) for GradPrune; \(\alpha_{BN}=0.001\) (**p. 7**). | This is an attack-specific utility–reconstruction trade-off result, not a formal privacy guarantee. |
| **ATS (Automatic Transformation Search)** — Gao et al., *Privacy-preserving Collaborative Learning with Automatic Transformation Search* (CVPR 2021; [arXiv:2011.12505](https://arxiv.org/abs/2011.12505)) | “Comprehensive evaluations demonstrate that the policies discovered by our method can defeat existing reconstruction attacks in collaborative learning, with high efficiency and negligible impact on the model performance.” **Abstract, p. 1.** | Honest-but-curious entity receiving other participants’ gradients: parameter server in centralized learning or arbitrary participant in decentralized learning (**Sec. 3.2, p. 3**). Search model: 10% data/50 epochs; ResNet-20 CIFAR-100 trained 200 epochs for reported overhead (**pp. 5–6**). | “Privacy-preserving” here is measured reconstruction degradation, not an \(\varepsilon,\delta\)-DP result. |
| **Count-Sketch aggregation / FedSKETCH** — Haddadpour et al., *FedSKETCH: Communication-Efficient and Private Federated Learning via Sketching* ([arXiv:2008.04975](https://arxiv.org/abs/2008.04975)) | “Theorem 1 implies that if we use smaller hash table either through using smaller \(m\) or \(t\), we will obtain stronger differential privacy.” **Sec. 4.2, p. 6.** The stated source theorem says Count Sketch “achieves \(t\cdot\ln(1+\cdots)\)-differential privacy with high probability” under Assumption 1 (**Theorem 1, p. 6**). | No reconstruction, membership, or other attacker experiment was reported. The paper’s privacy result is a conditional theorem about the released sketch, not an evaluated attacker. | Conditional \(\varepsilon\)-DP expression in Theorem 1 (high probability); **no empirical privacy/leakage metric reported**. | Utility experiment: MNIST, LeNet-5 CNN (60,000 parameters), 50 workers; homogeneous and non-IID partitions (**Sec. 7, p. 16**). This is a utility/convergence setting, not a privacy-attack setting. | Theorem assumption: input-vector entries i.i.d. \(\mathcal N(0,\sigma^2)\), bounded \(|s_i|\le C\); sketch has \(t\) arrays and \(m\) bins (**Assumption 1/Theorem 1, p. 6**). Utility figures use sketch sizes \((t,k)=(20,40)\), \((50,100)\), local updates \(\tau\in\{1,2,5\}\), half active devices/round (**pp. 16–18**). | Do not reinterpret the conditional Count-Sketch theorem as evidence against a gradient-inversion attacker: none was evaluated. |

## Boundaries

- No experiment, attack, data download, repository execution, or artifact inspection was performed.
- The accessible Soteria original source was abstract-only; all unavailable detail is explicitly **UNVERIFIED** rather than inferred from later audits.
- The five named defense categories produce six records because FedSKETCH and *Privacy For Free* are different source/mechanism pairings; retaining both prevents a false attribution of Count Sketch to the latter.
